# Curriculum Blueprint

The blueprint uses six phases across 90 days: first Japanese, reading Japanese, foundations, everyday Japanese, JLPT N5 core, and N5 completion. A blueprint defines course slots; it is not the same thing as an authored lesson.

Lesson statuses are truthful: `draft` means the slot exists but content is incomplete or template; `authored` means content is intentionally written and matches objectives; `reviewed` means it has passed curriculum, Japanese, and dependency review. The current 90 lesson records remain drafts pending the next authoring gate.
