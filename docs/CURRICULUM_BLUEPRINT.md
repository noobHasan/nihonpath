# Curriculum Blueprint

Nihon Path plans 90 lessons across six phases: first Japanese, reading Japanese, foundations, everyday Japanese, JLPT N5 core, and final N5 consolidation. Days 1–80 are reviewed. Days 81–90 remain draft and are intentionally delayed until required infrastructure gates are complete.

The blueprint defines course slots and canonical titles; it is not a substitute for authored lesson content. Lesson statuses remain truthful: `draft`, `authored`, or `reviewed`.
